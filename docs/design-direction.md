# 设计方向（当前：潮信 · 雾彩·清透 + 3D 订阅落地页）

> 本文取代 `docs/design.md` 第 5 节"视觉风格"。页面结构、合规要求不变。
> 当前设计稿：`design/v4/index.html`（日报订阅落地页，首页）。历史稿：v1 `design/*.html`、v2 `design/v2/`（深色）、v3 `design/v3/`（等距产业城）。

## 0. 品牌：潮信（2026-10-31 定名）

- 对外品牌叫**潮信**（"潮水按时涨落"，寓意准时、可信）；仓库名仍为 chainlens。原英文名 ChainLens 已被 Web3 Labs 的区块链浏览器注册商标，不再对外使用。
- 栏目结构（2026-10-31 定稿，不再用"早潮 / 晚潮"的叫法）：**盘前汇总**（美股开盘前，待上线）· **期权日报**（收盘后）· **研报日报**（每日）· **周报**（周日上午）。首屏副标题用"开盘前看消息，收盘后看信号"。
- 期权日报海报的署名暂时保持"KZG 期权 Pro"不变。
- Logo：等距小方块 + 一道浪（`design/v4/index.html` 导航里的 SVG）。

## 1. 定位变化（2026-10-31）

- **首页的第一任务是让用户订阅日报**，不是看盘。首页 = 日报宣传与订阅落地页，要精美、3D、可交互。
- 公司档案（`design/v4/company.html`）和看盘工具（`design/v4/stock.html`）是二级页面，已按本方向做成浅色。

## 2. 视觉：雾彩·清透（与日报海报同源）

视觉直接继承期权日报海报（`kzg-option-brief/docs/poster-style.md`，源头 `poster-kit` 的 `style.md`、`palette.md`），网站和海报是一家人：

| 项 | 约定 |
|---|---|
| 底色 | 白 → `#f7f8fc` 纵向过渡；可切换深色（`[data-theme="dark"]`），但以浅色为主 |
| 强调色 | 靛紫 `#5b4cff`，只给标题大字、编号、按钮、单一重点 |

| 字体 | 中文 Noto Sans SC（标题 900），数字与代码 Plus Jakarta Sans 800 |
| 标题 | 三层：黑色主句 → 靛紫大字 → 灰色副句 |

共用资源：`design/v3/assets/brand.css`（token 与组件）、`iso.js`（等距物件，移植自日报 `poster.js`）、`data.js`（按日报 `AI_CHAIN` 的 8 层）。

## 3. 首页（落地页）结构

1. **首屏**：大字"潮信" + "开盘前看消息，收盘后看信号"；邮箱订阅 + 栏目勾选；3D 倾斜手机自动播放期权日报海报，弹出期权日报、研报两条推送；四周漂浮黏土 3D 物件和 logo 硬币。
2. **三个栏目**：期权日报（新月 + 潮水）、研报日报（文件堆）、盘前汇总（日出 + 潮水，即将上线）三张卡，加周报一行；每张卡可展开样张。
3. **AI 产业岛**（Three.js）：漂在潮水上的黏土小岛，8 个站点按产业链顺序排列——矿石与金属锭、冷却塔（冒蒸汽）与风机（转动）、晶圆上的芯片、交换机与光纤（光点流动）、机柜（指示灯闪烁）、GPU（风扇转动）、数据中心园区与云朵、机器人与手机；传送带上的方块经过哪站就变成哪层的颜色；底座高度 = 当日热度；上空漂着成员公司 logo 硬币。可拖动、点击、按"下一站"导览，侧栏说明潮信每天在这一站看什么（期权日报 / 研报日报 / 盘前汇总）。
4. **拆开日报**：滚动驱动的爆炸图，海报逐层分离，镜头跟随当前版块。
5. **3D 盘面**：个股 K 线 + CP / 全市场分时 / 环节热度三视图，可旋转。
6. **日报怎么生成** → **样张**（期权日报海报、文字版、研报日报）→ 订阅 → 常见问题 → 合规页脚。
7. 手机适配：单列；产业岛镜头按宽高比自动拉远，说明面板移到下方。

补充（2026-10-31 第二轮）：
- **潮水**：着色器波浪 + 潮位涨落 + 一圈圈推向岸边的浪花，近岸浅青、远处深蓝；岛加沙滩、礁石、树、灯塔，海上有绕岛货船。
- **产业链运作**：传送带货物逐站变形（矿石 → 金属锭 → 芯片 → 光模块 → 服务器 → GPU → 云 → 应用）；能源站电线给数据中心 / 算力 / 云供电；网络站发数据光流。
- **吉祥物小更**：3D 知更鸟，叼着印有"潮"字的信封。首屏飞来投信并弹出"新潮信已送达"；产业岛上在灯塔和各站之间送信；订阅区站在邮筒旁，订阅成功后衔信飞走。
- **研报区**（落地页第 03 节）：今日研报调整做成可拖动的 3D 卡片环，点卡片看详情，可按上调 / 下调筛选。

第三轮（AI 产业镇）：
- 小岛改成**会运转的小镇**：环岛路、中央大道、三条横街（车道线、斑马线、人行道、行道树、路灯、长椅）；大道西接跨海拱桥（来自大陆），东到港口。
- **交通**：集装箱车、平板车（货物随街区变形）、小汽车、厢式车、潮信巴士，按车道行驶，跟车减速、路口让行；大道上的车从大桥开来、开进港口仓库。
- **街区**：站点模型 + 仓库（烟囱冒烟）+ 叉车往返搬货 + 穿反光背心戴安全帽的工人 + 机器人臂；人行道上有行人、两足送货机器人、六轮快递小车。
- **港口与电力**：岸桥把集装箱吊上靠港货船；电塔和电线把能源街区的电送到云、算力、数据中心。
- **天空**：潮信飞艇、海鸥、远处的云；灯塔上的小更来回送信。
- **首页首屏**：产业镇做全屏 3D 背景（镜头缓慢环绕 + 鼠标视差），手机悬浮在前；期权日报的大盘情绪、最强信号、最热环节和研报调整四张卡片从手机屏幕里 3D 飞出并悬浮，轮流缩回再飞出。
- 实现：`town.js`（道具库）+ `island.js`（场景只建一次，首屏和导览区两个相机共用；静态几何按材质合并，减少绘制次数）。
- **产业镇通栏**：导览区改为 100vw 铺满、高度接近视口，标题浮在左上，面板 / 标签 / 底栏悬浮在画面上；手机端镜头自动拉近。
- **镇里可点**：点卡车看装着哪个环节的货、点平板车看货物在哪个街区"加工"、点巴士 / 小汽车、点工人 / 行人 / 机器人、点广告牌跳公司档案、点灯塔 / 小更 / 飞艇 / 岸桥 / 货船看说明；气泡跟着目标走。
- **小镇细节（第四轮）**：大道三个路口有红绿灯（东西 / 南北轮流放行，车辆到停止线等灯，行人等绿灯过斑马线）；每个街区屋顶有广告牌，写着这一环节当天成交最热的公司（logo、涨跌、量倍数）；港口入口有"今日市场"大屏和滚动字幕；所有车辆有车头灯和尾灯。
- **夜晚模式**（首屏右下角和导览区底栏的按钮）：白天 → 黄昏 → 夜晚约 2.6 秒平滑过渡：天空、雾、海色变深，太阳光转冷，路灯亮起并在路面铺出光晕，车头灯打出光束，仓库窗户亮灯，灯塔光束变亮，星星和月亮出现。首屏文字同时切成浅色。
- 技术备注：用 `scene.environment` 时，three.js r170 忽略材质自己的 `envMapIntensity`，环境光强度要通过 `scene.environmentIntensity` 控制（白天 0.62，夜晚接近 0）。
- **画质分级**（`design/v4/assets/quality.js`）：按设备定档 high / medium / low（触屏 + 小屏、CPU 核数、内存、"减少动态效果"）；档位决定渲染像素比、阴影开关与贴图尺寸、行人 / 车辆 / 海鸥数量、海面细分。主循环按真实时间测帧率，低于 24 帧累计 3 秒自动降一档（阴影关掉、像素比降低立即生效）。`?q=low|medium|high` 可强制指定。
- **公司楼与串门**：每个街区沿远离大道的一边排公司楼（高度 ≈ 市值，楼顶 logo 招牌，夜里亮窗），点楼进公司档案；公司档案页顶部有该街区的 3D 小景，点旁边的楼可切换公司。
- **看盘页**：新增财报日（主图虚线竖线 + 标签 + 事件标记 + "下次财报 · N 天后"）和"最热合约"条（近 60 日期权成交最大的 6 天，格式同期权日报）。

- `design/v4/subscribe.html` **订阅流程**：已发确认邮件 → 确认成功（选栏目、撒花、小更出发）→ 管理偏好（栏目 / 关注公司 / 送达时间 / 格式）→ 链接失效；`unsubscribe.html` 退订（可改为只保留部分）；`email.html` 600px 单列邮件模板（缩略海报 + 要点 + 关注公司 + 研报摘录 + 一键退订）。

- **⌘K 全局搜索**（`design/v4/assets/search.js`，所有页面共用）：导航右侧"搜索 ⌘K"按钮，或 ⌘K / Ctrl+K / `/` 打开；搜公司（代码、中文名、环节）、产业镇街区、栏目与页面、归档日期（如 `10-28`）；↑↓ 选、Enter 打开、Tab 在"公司档案 / 看盘"之间切换；最近打开的 5 条记在本地。纯前端子串匹配，没有后端。
- **实验性深色模式**（`design/v4/assets/theme.js`）：导航右侧的 🌙 按钮或 ⌘K 里"切换深色 / 浅色模式"；记在 localStorage，`<html data-theme="dark">` 用 brand.css 里的深色 token。浅色仍是默认和主推；海报（`.kp`）、3D 场景、手机屏幕、邮件模板保持浅色；首页切到深色时首屏与产业镇一起进入夜晚。各页硬编码的白底用 `[data-theme="dark"]` 覆盖（各自 CSS 文件末尾）。
- **产业镇深链接**：`index.html#island?station=chip` 直接定位到某个街区（搜索、分享链接都用它）；在镇里切换街区时地址栏同步更新。

3D 共用模块：`design/v4/assets/clay.js`（黏土材质、等距物件转 3D、logo 硬币、8 个站点模型、小更、货物、灯塔、货船、树）。

## 4. 动效原则

- 动效要讲清一件事：手机滚动 = "每天推送到手机"；爆炸图 = "日报由哪些版块组成"；柱子长出 = "数据怎么来的"。
- 3D 场景离开视口时暂停渲染；尊重系统"减少动态效果"设置。
- Three.js 以普通脚本 + 动态 `import()` 加载（配合 importmap），设计稿可直接双击打开。

## 5. 上线前必须解决（非设计问题）

- **数据授权**：日报数据来自 KZG 个人网站，日报仓库约定"不公开分发"；Finnhub 免费档仅限个人非商用。公开招募订阅前需取得授权或更换数据源。
- **合规**：订阅保持免费；"偏多 / 偏空"统一表述为期权数据面倾向；页脚与 FAQ 写明不构成投资建议（见 `docs/compliance.md`）。

## 7. 历史版本为什么被替换

- v1（浅色卡片）：没有主角、装饰代替信息、像 AI 模板。
- v2（深色控制室）：专业但和日报品牌脱节；用户更想要浅色、年轻活力。
- v3（等距产业城）：品牌对了，但首页目标从"看产业链"变为"订阅日报"，产业城降为备选素材。

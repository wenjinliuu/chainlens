# 合规原则（必读）

ChainLens 的定位是**公开信息的整理与可视化**。以下规则优先于任何功能需求，写代码、写文案、写 AI 提示词时都要遵守。

## 1. 不做的事

- 不给出买入 / 卖出 / 持有建议，不给出买卖时机、价格点位或走势预测。
- 不承诺收益，不使用"稳赚""翻倍""机会""抄底"等字样。
- 不以会员、社群、付费订阅等形式提供证券投资分析或建议。
- 不引导开户（包括港美股开户），不做站外导流到交易平台。
- 不发布研报 PDF 原文，不转载付费订阅（Substack 等）的原文内容。

## 2. 要做的事

- 研报内容只展示：机构名、日期、评级、目标价、**3 条以内**的要点摘要、来源说明。
- 所有数据标注来源与更新时间；行情标注延迟。
- AI 生成或 AI 提炼的内容标注"AI 整理"。
- 全站页脚与每封邮件带风险提示：

  > 本站内容为公开信息整理，不构成任何投资建议。市场有风险，投资需谨慎。

- "信息集中出现"等聚合功能只描述事实（出现了几次、什么事件），不作方向性判断。

## 3. 文案自检清单

上线前对页面文案、邮件模板、AI 提示词逐条检查：

- [ ] 没有"建议""推荐买入/卖出""目标位""看涨/看跌"之类的指令性措辞
- [ ] 没有收益承诺或夸大表述
- [ ] 研报只有摘要，没有原文段落
- [ ] 有来源、时间、延迟说明
- [ ] 有风险提示

## 4. 收费

如果以后要收费，收费内容应限于工具、可视化、模板、行业资讯等，不得是投资分析或建议本身；收款需要营业执照。具体方案届时再单独评估。

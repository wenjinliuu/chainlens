# 产品设计

## 1. 定位

**AI 产业链情报台**，不是大杂烩资讯站。

- 核心单元是**个股**：一只股票一个页面，把不同来源的公开信息按时间线叠在一起。
- 覆盖范围跟随期权日报的"AI 优先"口径：算力芯片、存储、光模块 / 网络、电力与能源、矿企转算力、原材料、云厂商等；非 AI 大市值公司只作补充。
- 差异化：别人有行情、有新闻，但很少把**期权异动 + 研报目标价变动 + 个股新闻**放在同一条时间轴上。

## 2. 站点结构

```
/                     今日驾驶舱
/stock/:ticker        个股页
/chain                产业链地图
/daily                日报 / 海报归档（日历）
/daily/:date          某一天的回放（驾驶舱快照 + 当日海报）
/subscribe            邮件订阅 / 自选股
/about                关于 & 免责声明
```

## 3. 页面设计

### 3.1 今日驾驶舱（首页）

电脑版用 **Bento 格子布局**，信息密度高但留白充足。

| 卡片 | 内容 | 交互 |
|---|---|---|
| 今日一句话 | 当日总览（来自期权日报的盘前概述） | 点开看完整日报 |
| 产业链热力图 | 按环节分组的方块图，颜色 = 当日涨跌幅，大小 = 市值 | 悬停看数值，点击进个股 |
| 期权异动榜 | 按"相对自身波动"的 CP 信号排序（沿用期权日报的分布阈值口径） | 点击进个股页期权栏 |
| 研报变动流 | 评级 / 目标价调整：机构、旧→新、日期 | 点击进个股页研报栏 |
| 个股新闻流 | 重要个股新闻，带来源和时间 | 点击跳原文 |
| 信息集中出现 | 同一周内期权异动和研报调整同时出现的股票（见 3.6） | 点击进个股 |
| 今日海报 | 当日海报缩略图 | 下载高清图 |

### 3.2 个股页（核心）

自上而下：

1. **头部**：代码、名称、所属产业链环节、最新价、涨跌（绿涨红跌）、数据更新时间与延迟说明。
2. **主图**：K 线（TradingView Lightweight Charts）
   - **事件标记**：在 K 线上打点 —— 期权异动 / 研报评级或目标价调整 / 重要新闻，三类用不同图标和颜色；悬停显示详情卡片。
   - **目标价区间带**：在 K 线背后画研报目标价的最低 / 平均 / 最高区间（半透明带），随时间变化。
3. **期权副图**：CP 比、LEAP CP 比的历史，叠加该股自身的分布区间（如 ±1σ 带）。
4. **研报时间线**：每篇研报一张卡片 —— 机构、日期、评级、目标价、3 条以内要点、来源。**不放 PDF 原文**。
5. **新闻时间线**：标题、来源、时间、链接。
6. **上下游**：该股在产业链地图中的上下游公司，横向小卡片。

### 3.3 产业链地图

- 节点 = 公司，按环节分列（上游 → 下游），连线 = 供应关系。
- 节点颜色 = 当日涨跌，节点光晕 = 当日是否有期权异动 / 研报调整。
- 点击节点：侧边弹出该股摘要卡，再点进入个股页。
- 关系数据先手工维护一份 JSON（见 data-sources.md），以后再考虑半自动。

### 3.4 日报 / 海报归档

- 日历视图，每天一个格子显示当日海报缩略图。
- `/daily/:date` 是**时间回放**：复原那一天的驾驶舱快照 + 当日海报 + 文字日报。
- 海报页提供**高清图下载按钮**。

### 3.5 订阅

- 输入邮箱 → 确认邮件（double opt-in）→ 选择自选股（可选）。
- 邮件内容：缩略预览 + 3~5 条要点 + "查看完整版"链接回站点；底部一键退订。
- 不在邮件里放整张长图。

### 3.6 "信息集中出现"标记

规则（由代码固定，不交给 AI 判断）：同一只股票在最近 N 个交易日（默认 5）内，同时出现 ≥1 次期权异动和 ≥1 次研报评级 / 目标价调整，即进入该列表。

**措辞只描述事实**：如"本周期权异动 2 次，研报调整 1 次"。禁止"买入""机会""看涨"等字样。

## 4. 电脑版与手机版

### 电脑版

- 追求"酷炫"：Bento 布局、细腻的卡片动效（悬停微抬、数字滚动）、热力图和产业链图的过渡动画。
- **⌘K / Ctrl+K 命令面板**：全局搜索代码 / 公司名 / 日期，直接跳转，营造"终端感"。
- 宽屏下个股页主图与右侧研报栏并排。

### 手机版

不是把电脑版缩小，而是重新排：

- 首页改为**竖向卡片流**（类似小红书信息流），一张卡片 = 一条信号或一只股票。
- 底部 Tab：今日 / 产业链 / 自选 / 日报。
- 个股页用**分段切换**：行情 | 期权 | 研报 | 新闻。
- K 线支持手势缩放；事件标记点击弹出底部抽屉。
- 支持 **PWA**：添加到主屏幕，像 App 一样打开。

## 5. 视觉风格

- 浅色、淡雅底色 + **多彩点缀**，高级的 Apple 式质感（大圆角、柔和阴影、毛玻璃、大量留白）。
- 方向色：**绿 = 涨 / 偏多，红 = 跌 / 偏空**（全站统一，图表也一样）。
- 可选深色模式，作为第二优先级。
- 字体：中文 PingFang / 思源黑体，数字用等宽数字（tabular-nums）。
- 每类事件固定一种强调色，全站一致：期权 / 研报 / 新闻。

## 6. 分享与引流

- 每个个股页、每天的日报自动生成 **OG 分享图**，发公众号 / 小红书 / 微信时直接带卡片。
- 海报沿用 poster-kit 的风格，保证站内外视觉统一。

# AI 产业镇重构方案

写于 2026-11-01。现在的镇（`design/v4/assets/island.js`）：8 层 = 8 个等大矩形街区，2 行 × 4 列，环岛路 + 中央大道 + 三条横街。好处是交通、红绿灯、广告牌都跑通了；问题是**太规整**（像停车场）、**只细到层**（环节只在面板里列出）、**没有未来的位置**（未上市巨头、新赛道）、**信号体现得少**（只有底座高度、广告牌、工人一句话）。这份方案回答四个问题：分区怎么细、布局怎么自然、扩展区放哪、期权 / 研报信号怎么上镇。

## 1. 分区：8 个片区 × 子地块

层（片区）不变，仍对应 kzg-option-brief 的 `AI_CHAIN` 八层，便于数据对接；**每个片区内按环节（子链）分小地块**，公司楼按子链分组，地块有自己的牌子和一个专属小道具。

| 片区 | 子地块（环节） | 地块道具 | 现有公司（示例名单） | 备注 |
|---|---|---|---|---|

规则：
- 子链名单沿用 `design/v3/assets/data.js` 的 `layers[].segs`，新增子链先建空地块（有牌子、道具、无公司楼），名单从 kzg `config.js` 的 `AI_CHAIN` 对齐后补。
- 地块面积 ∝ 成员数（最少 1 格），片区面积 = 子地块之和 + 公共空间（广场 / 停车场 / 绿地）。
- 公司楼高度仍 ≈ √市值；同一子地块的楼成组，组前立牌子（子链名 + 当日热度）。

## 2. 布局：从棋盘到小镇

保留：岛、港口（东）、跨海大桥（西）、灯塔、环岛路、交通系统（Path 已支持任意折线 / 曲线）。改动按"看起来像自然长出来的"原则：

1. **片区大小不等、边界不规则**：芯片 2 格宽，原材料 0.6 格；街区轮廓用圆角多边形 / 切角，不再是清一色矩形。
2. **大道微弯**：中央大道改成一条缓弯的贝塞尔（西桥头 → 东港口），横街错位、不对齐，路口改成"路口表"（任意位置、任意方向）而不是三个固定 x。
3. **一条小河**：从北岸流入、穿过能源与芯片片区之间、在港口旁入海；两座桥；河边是公园和长椅。小河的流向在等距视角下尽量左右走（上下走会显得生硬）。
4. **地势**：北面一道小山坡（风机、电塔在坡上），南面平坦朝港口；海岸线加一个半岛（发射场）和一个小湾（码头）。
5. **公共空间**：中心广场（潮信钟楼 / 市场大屏搬到这里）、每片区一个口袋公园、港口前的集装箱广场。
6. **布局数据化**：`assets/town-layout.js`（或 JSON）描述片区多边形、子地块矩形、路网折线、河流样条、地标点；`island.js` 只读布局，不再写死 `COLS / ROWS / BLOCKS`。这样 M1 后可以用同一份布局生成 2D 产业链图。

## 4. 信号怎么上镇（规则固定、代码驱动，不让 AI 决定）

| 数据 | 来源 | 镇上的表现 |
|---|---|---|
| 环节热度（成员量倍数中位数） | 期权日报 `segments` | 底座高度（已有）+ 街区内平板车数量 0 ~ 3 + 工人数量 + 烟囱冒烟频率 |
| 个股期权方向明确（偏多 / 偏空） | 期权日报 `picks` | 楼顶升旗：绿旗 = 偏多、红旗 = 偏空；可信度高 → 楼顶射灯；楼身窗灯闪 1 分钟 |
| 研报评级 / 目标价调整 | 研报日报 | 楼前立"目标价牌"（箭头上 / 下）；首次覆盖 → 门口剪彩彩带 |
| 新闻 / 公告 | 新闻层 | 楼前报童（新闻）/ 门口公告栏（公告） |
| 周报环节轮动 | 周报 `rotation` | 潮信巴士车身滚动字幕：本周最热 → 最冷；飞艇横幅 = 本周方向 |
| 全市场情绪 | 期权日报 `mood` | **天气**：偏乐观 = 晴、中性 = 多云、偏谨慎 = 阴 + 小雨（雨粒子）；夜晚模式照旧 |
| 时段 | 本地时间 | 开盘前 = 清晨光（盘前汇总）、收盘后 = 傍晚光（期权日报） |

合规：所有表现只描述数据面（"今日偏多"）与事实（"上调目标价"），气泡文字继续过合规扫描。

自动更新：pipeline 每日产出 `data/town/{date}.json`：
```json
{ "date": "2026-10-30", "weather": "sunny | cloudy | rain", "segHeat": { "光模块": 2.3 },
  "towers": { "LITE": { "dir": "偏多", "conf": "高", "flag": true, "lamp": true, "target": "up", "news": 2 } },
  "boards": [{ "seg": "光模块", "t": "LITE" }], "bus": ["光模块", "存储", "GPU/加速器"], "blimp": "本周偏多" }
```
前端只读这份 JSON；没有当天数据时用上一份并在角落标"数据截至 …"。时间回放（归档页）可以把这份 JSON 按日期切换，让镇"回到那一天"。

## 6. 风险

- 性能：道具数量翻倍。继续按材质合并静态几何、按画质分级裁剪（手机端只留地块牌子与楼，不要旗 / 粒子）。
- 交通：第 2 步改路网会动到跟车、让行、红绿灯，单独做并回归（车辆不穿楼、不堵死）。
- 名单：新子链的公司名单要和 kzg `config.js` 对齐，不在这里拍脑袋加公司。
